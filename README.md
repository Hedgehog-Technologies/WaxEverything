# Waxed Item Frame

A Minecraft mod to allow players to "lock" an item frame by using Honeycomb on it. "Locked" item frames cannot have items rotated or removed. 

## Key Features
### 1.0.0
- Initial Release

## Usage
1. Apply Honeycomb directly to item frame (with an item in it) to "lock" it
2. ???
3. Use axe on item frame to "unlock" it.
